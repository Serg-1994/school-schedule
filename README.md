# Школьное расписание

Десктопное приложение для автоматизации составления школьного расписания на Python с PyQt6 и SQLite.

## Структура проекта

- `database/` - модуль базы данных
- `models/` - модели данных (Teacher, Class, Subject, Schedule)
- `views/` - интерфейс (MainWindow с вкладками)
- `controllers/` - контроллеры (MainController)
- `main.py` - точка входа

## Функционал

- **Вкладка Расписание**: Выбор учителя, календарь, планирование уроков на день.
- **Вкладка Учителя**: Список учителей с функциями добавления/редактирования/удаления. Двойной клик показывает профиль с часами за месяц.
- **Вкладка Классы**: Управление классами.
- **Вкладка Предметы**: Управление предметами.

## Запуск

1. Установите зависимости: `pip install PyQt6`
2. Создайте базу данных: `python database/database.py`
3. Добавьте тестовые данные: `python test_data.py`
4. Запустите приложение: `python main.py`

## Использование

- Переключайтесь между вкладками для управления справочниками.
- В расписании выбирайте учителя и дату для планирования уроков.
- Расчет часов доступен в профиле учителя.
