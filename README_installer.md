# School Schedule Installer

## Установка программы

1. Разархивируйте файл `school_schedule_installer.zip`.
2. Запустите `School Schedule_installer.exe` (требуются права администратора).
3. Следуйте инструкциям установщика.
4. После установки программа будет доступна на рабочем столе и в меню Пуск.

## Запуск программы

После установки запустите ярлык "School Schedule" на рабочем столе или найдите в меню Пуск.

## Удаление программы

Используйте стандартное удаление программ в Windows или запустите uninstall.exe из папки установки.
